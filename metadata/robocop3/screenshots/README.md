# Скриншоты — RoboCop 3

Сюда положить итоговый набор для карточки RuStore:

```
./scripts/screenshots.sh robocop3 6 5
```

* Разрешение ставится автоматически в 16:9 (1920x1080), снимки в `screenshots/robocop3/`.
* Во время съёмки играть: геймплей, прыжки, стрельба, моменты с вертолётным модулем.
* Рекомендуемый набор (3–10 штук):
  1. Экшен-кадр с врагами (самый эффектный — первым)
  2. Момент с оружием/даджампом
  3. Уровень с узнаваемой локацией (крыши, промзона)
  4. Кадр редактора раскладки (показывает удобство управления)
  5. Кадр паузы/слотов сохранений (миниатюры)
* Файлы из screenshots/robocop3/ скопировать сюда и коммитить (метаданные в git),
  исходники съёмок остаются локально.
