# Метаданные для RuStore

Тексты карточки приложения для публикации в RuStore. Папка на каждую игру —
свои тексты (как и сборка: одна игра — одно приложение `com.dendybox.app.<flavor>`).

## Структура

```
metadata/
  robocop3/
    title.txt               — название приложения (лимит 30 символов)
    short_description.txt   — краткое описание (лимит 80 символов)
    full_description.txt    — полное описание (лимит 4000 символов)
    release_notes.txt       — «что нового» для первой версии
    category.txt            — рекомендуемая категория (справочно)
    age_rating.txt          — рекомендуемый возрастной рейтинг (справочно)
    tags.txt                — теги/ключевые слова (справочно)
    screenshots/            — сюда положить снятые скриншоты
                              (./scripts/screenshots.sh <flavor>, 3–10 шт.,
                              лучшие — в начало; первый решает, установят ли)
    icon.png                — исходная иконка игры (кладёте вы)
    icon512.png             — иконка 512×512 для карточки RuStore
                              (генерируется из icon.png скриптом, коммитим)
```

## Иконка игры

Положите исходник в `metadata/<flavor>/icon.png` (лучше квадрат 512×512 или больше,
PNG, допустима прозрачность). Дальше всё автоматически:

* `./scripts/make_icons.sh <flavor>` — или просто сборка `build_release.sh`:
  из icon.png готовится adaptive-иконка лаунчера (подхватывается APK) и
  `icon512.png` для карточки магазина;
* если у исходника прозрачные углы («иконка с рамкой») — арт ставится целиком
  на подложку среднего цвета арта; если квадратный непрозрачный — арт заливает
  весь холст, маска лаунчера сама режет края;
* обновили icon.png — просто пересоберите; иконка перегенерируется сама.

## Чек-лист публикации (RuStore)

1. Подписанный релиз: `./scripts/build_release.sh <flavor>`
2. Скриншоты 16:9: `./scripts/screenshots.sh <flavor> 6 5` — играть во время съёмки
3. Иконка: `metadata/<flavor>/icon512.png` (генерируется из icon.png автоматически —
   см. «Иконка игры» выше; при сборке она и так обновится)
4. Заполнить карточку текстами из файлов выше (скопировать как есть)
5. Возрастной рейтинг — по содержимому (см. age_rating.txt), категория — category.txt
6. Загрузить APK, приложить скриншоты, отправить на модерацию
