# Мультиром DendyBox (сборник игр в одном ROM)

Инструмент собирает **один файл .nes** из нескольких игр с меню выбора —
по образу классических пиратских мультикартов Денди («N-in-1»). Полученный
ROM — обычный картридж: работает в DendyBox как любая игра (положите в
`roms/` + запись в `games.json`), а также в FCEUmm/Mesen, и даже может быть
прошит на реальную плату.

## Быстрый старт

```bash
./scripts/make_multicart.sh -o kontra.nes \
    -t "КОНТРА" -t "SUPER C" -t "PROBOTECTOR" \
    roms/kontra.nes roms/superc.nes roms/probotector.nes
```

Результат: `kontra.nes` — сборник с меню (↑↓ — выбор, Start/A — запуск,
RESET приставки — возврат в меню). Дальше как обычно:

```bash
# обычный flavor-сборка DendyBox с этим ROM:
cp kontra.nes roms/         # roms/kontra.nes
# + запись в roms/games.json: { "kontra.nes": { "flavor": "kontra", "title": "Контра. Сборник" } }
./scripts/run.sh kontra
```

## Требования к играм

Схема рассчитана на игры **UNROM (iNES mapper 2)**, как оригинальная Contra:

| Параметр      | Значение                                        |
|---------------|-------------------------------------------------|
| Mapper        | 2 (UNROM)                                       |
| PRG-ROM       | ровно 128 КиБ (8 банков по 16 КиБ)              |
| CHR           | 0 (CHR-RAM, игра сама заливает тайлы)           |
| Тренер/батарейка | нет                                          |
| Зеркальность  | одинаковая у всех игр сборника                  |

Сборщик проверяет каждый ROM и отклонит неподходящий с объяснением.
Под это описание подходят Contra (все регионы), Super C / Probotector и
большинство самодельных хаков на их базе. Пиратские «Контры» с другими
mapper'ами без ручной конвертации не войдут — сборщик сообщит mapper ROM'а.

## Как это устроено

Формат — **NES 2.0 Mapper 324 (FARID_UNROM_8-IN-1)**, плата мультикарта
для UNROM-игр (разработка Farid, эмулируется FCEUmm `src/boards/faridunrom.c`):

* PRG до 1 МиБ = 8 «окон» по 128 КиБ; внутри окна игра видит обычный UNROM
  со **своим фиксированным банком** — поэтому игры **не требуют патчей**.
* Окно 0 — меню (этот репозиторий, `menu/menu.asm`), окна 1–7 — игры
  (максимум 7). Регистр окна защищён от случайной перезаписи игрой:
  внешние биты меняются только записью с битом 7, а обычные UNROM-игры
  пишут номера банков 0–7.
* Кнопка RESET очищает выбор окна → возврат в меню.
* Меню живёт в фиксированном банке окна 0; запуск игры — через трамплин
  в RAM ($0000): `LDA #окно; STA $C804; JMP ($FFFC)`. Трамплин в RAM
  обязателен: после записи выбора окна код меню исчезает из шины.

Меню рисуется в CHR-RAM, шрифт 8×8 (латиница + кириллица) генерируется
из DejaVu Sans Mono (`font_gen.py`); названия игр и текст экрана вшивает
сборщик (`make_multicart.py`). Размер ROM: 128 КиБ × (1 + число игр).

## Файлы

```
tools/multicart/
├── make_multicart.py      — сборщик мультирома (python3, без зависимостей)
├── build_menu.sh          — пересборка меню (при изменении menu.asm)
├── font_gen.py            — генератор шрифта (нужен Pillow)
├── menu/
│   ├── menu.asm           — исходник меню (asm6f)
│   ├── font.inc           — сгенерированный шрифт (коммитится)
│   └── multicart_menu.bin — собранное меню (коммитится)
├── asm6f/                 — ассемблер asm6f 1.6 (freem/asm6f, public domain)
└── test/                  — тесты (см. test/README)
```

## Тесты

`test/` содержит каркас для проверки без телефона: две синтетические
«игры» (заливают экран зелёным/розовым), генератор тестовых ROM и
libretro-хост `mc_harness.c` (скриптовый джойстик, статистика кадра,
RESET). Полный прогон: сборка FCEUmm для Linux (`git clone … && make`),
сборка харнесса (`gcc -O2 -o mc_harness mc_harness.c -I <fceumm>/src/drivers/libretro/libretro-common/include -ldl`),
сборка мультирома из тестовых игр и сценарий «меню → запуск 1 → RESET →
запуск 2» с проверкой цвета экрана.

## Ограничения

* Только UNROM-игры 128 КиБ с CHR-RAM (см. таблицу выше).
* Зеркальность общая на весь сборник (как на реальной плате): если у игр
  она разная, сборка падает с ошибкой — приводите ROM'ы к одной.
* Нет PRG-RAM/батарейки: игры с сохранениями (SRAM) не войдут.
* В меню до 7 игр, название — до 21 символа (латиница/кириллица).
* Держите списки для сетевой игры честными: сборник детерминирован, так
  что netplay между двумя одинаковыми сборниками работает.
